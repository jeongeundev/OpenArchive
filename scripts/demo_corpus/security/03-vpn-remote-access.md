# 원격접속 VPN 사용 규칙

## 접속 대상

사무실 밖에서 사내 시스템에 접속하려면 반드시 VPN을 거친다. 사내 위키, 인사시스템, 관제 화면, 데이터베이스 관리 도구가 대상이다. 사내망을 거치지 않는 외부 서비스는 VPN 없이 쓴다.

## 사용 조건

회사가 지급한 노트북에서만 접속한다. 개인 컴퓨터, 가족의 기기, 공용 컴퓨터에는 VPN 클라이언트를 설치하지 않는다. 접속할 때 계정 비밀번호와 인증 앱의 일회용 번호를 함께 입력한다. 요건은 [[비밀번호와 다단계 인증 기준]]에 있다.

## 네트워크

집에서는 개인 공유기의 무선 네트워크를 쓴다. 카페, 공항, 호텔의 공용 와이파이에서는 접속하지 않는다. 부득이하게 이동 중 접속이 필요하면 휴대전화의 테더링을 쓴다.

## 국외 접속

국외에서의 접속은 기본적으로 차단한다. 해외 출장으로 필요한 경우 출장 기간과 국가를 미리 등록하면 그 기간에만 열린다. 등록 없이 국외에서 접속을 시도하면 계정이 자동으로 잠긴다.

## 세션

접속 후 8시간이 지나면 자동으로 끊긴다. 30분 동안 아무 동작이 없어도 끊긴다. 끊긴 뒤에는 다시 인증한다. 자리를 비울 때는 세션을 끊지 않더라도 화면을 잠근다. 단말 설정은 [[업무용 단말 보안 설정]]에 있다.

## 재택근무와의 관계

재택근무 신청과 VPN 사용은 별개다. 신청 없이 재택하는 날이 생겨도 VPN은 쓸 수 있다. 근무 제도 자체는 [[재택근무 운영 지침]]을 따른다.

## 기록

접속 시각, 계정, 접속지 국가가 기록된다. 이상 접속이 확인되면 정보보안팀이 계정을 잠그고 본인에게 연락한다.
