# 업무용 단말 보안 설정

## 기본 설정

지급받은 날 디스크 암호화를 켠다. 화면 잠금은 5분으로 설정하고 잠금 해제에 비밀번호 또는 생체 인증을 요구한다. 운영체제와 브라우저의 자동 업데이트를 끄지 않는다.

## 소프트웨어 설치

업무에 필요한 소프트웨어는 사내 자산관리 도구를 통해 설치한다. 목록에 없는 프로그램이 필요하면 정보보안팀에 요청한다. 인터넷에서 받은 설치 파일을 임의로 실행하지 않는다. 무료 유틸리티에 광고 프로그램이 함께 설치되는 사례가 반복해서 확인됐다.

## 외부 저장 장치

USB 저장 장치는 기본적으로 쓰기가 차단되어 있다. 업무상 필요하면 사유를 적어 기간을 정해 허용받는다. 읽기는 제한하지 않지만, 출처를 모르는 장치는 연결하지 않는다.

## 자료 반출

업무 자료를 개인 클라우드, 개인 메일, 메신저 개인 대화로 옮기지 않는다. 외부와 파일을 주고받아야 하면 사내 파일 전송 시스템을 쓴다. 이 시스템은 다운로드 기록을 남기고 기간이 지나면 자동으로 지운다.

## 분실

노트북을 잃어버리면 즉시 정보보안팀에 알린다. 원격으로 잠그고 필요하면 초기화한다. 늦게 알릴수록 피해가 커지므로 확실하지 않은 단계에서도 먼저 알린다. 접수 절차는 [[정보보안 사고 대응 절차]]에 있다.

## 점검

자산관리 도구가 암호화 여부, 화면 잠금 설정, 미승인 소프트웨어를 매일 확인한다. 기준에 맞지 않으면 본인에게 알림이 가고, 7일 안에 고치지 않으면 사내망 접속이 제한된다.
