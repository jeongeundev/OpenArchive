# 비밀번호와 다단계 인증 기준

## 비밀번호 요건

최소 12자 이상으로 만든다. 영문 대소문자, 숫자, 특수문자를 섞는 규칙은 강제하지 않는다. 길이가 짧은 복잡한 문자열보다 긴 문장 형태가 실제로 더 안전하고 기억하기도 쉽다. 다만 사전에 있는 단어 하나만 쓰거나 회사명, 생년월일, 연속된 숫자는 막는다.

## 변경 주기

정기 변경을 요구하지 않는다. 주기적으로 바꾸게 하면 뒤에 숫자만 하나씩 올리는 방식으로 이어져 오히려 약해진다. 대신 유출 정황이 확인되면 즉시 바꾸게 한다.

## 재사용 금지

회사 계정의 비밀번호를 외부 서비스에서 쓰지 않는다. 외부 서비스가 털리면 회사 계정이 함께 뚫린다. 유출된 비밀번호 목록과 대조해 일치하는 것이 발견되면 해당 계정을 즉시 잠그고 재설정을 요구한다.

## 다단계 인증

모든 사내 시스템에 다단계 인증을 적용한다. 인증 앱의 일회용 번호를 기본으로 하고, 문자 메시지는 앱을 쓸 수 없는 경우에만 허용한다. 문자는 번호 이전 공격에 취약하므로 관리자 권한 계정에는 쓰지 않는다.

## 관리자 계정

서버, 데이터베이스, 결제 시스템의 관리자 계정에는 하드웨어 보안키를 추가로 요구한다. 대상과 발급 절차는 [[서버 접근권한 승인 절차]]에 있다.

## 분실과 초기화

인증 수단을 잃어버리면 정보보안팀이 본인 확인 후 초기화한다. 메신저나 메일 요청만으로 초기화하지 않는다. 이 절차를 건너뛰는 것이 사회공학 공격의 가장 흔한 통로다.
