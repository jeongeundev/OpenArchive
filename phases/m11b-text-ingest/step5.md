# Step 5: adr-text-ingest

## 배경 — 결정을 기록하고 문서를 코드와 맞춘다

step 0~4가 코드를 바꿨다. 이 step은 **그 결정의 근거를 ADR-035로 남기고**, 흩어진 문서가
지금의 코드와 어긋나지 않게 맞춘다. 코드는 한 줄도 고치지 않는다.

이 phase가 해소하는 문서 차원의 부채는 셋이다.

1. `docs/ROADMAP.md` 1단계의 착수 전 필요한 결정 중 **"텍스트 직접 생성 API 의미론(ADR-017
   어휘 정합)"과 "CORS 정책"**이 아직 결정으로 기록되지 않았다
2. `docs/PRD.md`가 프로그래매틱 공급을 **"정의가 구현을 앞서는 유일한 항목"**으로 적고 있는데,
   그 절반이 구현됐다
3. `ADR-017`의 어휘(원본 파일 / 추출 텍스트 / 텍스트 버전)가 **원본 파일이 없는 문서**를
   상정하지 않았다

## ⚠️ ADR 번호는 035다 — 033·034를 채우지 마라

현재 `docs/ADR.md`의 마지막은 **ADR-032**다. 033과 034가 비어 보이지만 **예약된 번호다.**

- **ADR-033** — ZIP 대량 투입 (이슈 #54)
- **ADR-034** — 프로그래매틱 인증 토큰 (M11-c)
- **ADR-035** — 텍스트 공급 API 의미론 ← **이 step**
- **ADR-036** — MCP 쓰기 도구 (M11-d)

번호를 앞당기거나 033·034를 새로 쓰지 마라. 이 phase의 ADR은 **035 하나뿐**이다.

## 이전 step에서 만들어진 것

- **step 0** — `backend/app/services/documents.py`에 `create_text_document` 신설,
  `create_document`는 파싱 어댑터로 축소, INSERT는 공통 헬퍼 한 곳. 직접 공급 문서는
  `filename` NULL. 텍스트 공급 유형은 `txt`·`md`
- **step 1** — `POST /api/documents/text`. 인증은 세션 쿠키(`require_user_id`). 파생 4종
  (임베딩 잡·텍스트 버전·edge·위키링크) 동등성을 테스트가 단언한다
- **step 2** — `examples/ingest_text.py`(표준 라이브러리 전용 공급 클라이언트) +
  `tests/test_architecture.py`의 독립성 단언 + `scripts/check.sh`의 ruff 경로 확장
- **step 3** — `scripts/seed_demo.py`의 가짜 파일명 우회 제거
- **step 4** — `TextEditor.tsx`가 `filename === null`이면 "문서 텍스트"로 표시

**작업 전에 실제 코드를 읽어 확인하라.** 위 요약과 코드가 다르면 코드가 맞다. 특히
`git log --oneline main..HEAD`와 `git diff --stat main -- backend/app/services/`로 실제
변경 범위를 확인한 뒤 문서를 써라 — 추정으로 쓴 수치를 ADR에 남기지 마라.

## 작업

### 1) `docs/ADR.md` 끝에 ADR-035를 추가한다

제목: **ADR-035: 텍스트 공급 API는 코어에 텍스트 우선 진입점을 만든다 — 원본 파일 없는 문서**

아래 결정을 전부 담되, 근거를 이 phase의 **실제 코드와 실측**에서 가져와라.

- **결정 1 (진입점).** 라우터가 가짜 파일명을 지어내 기존 파일 진입점을 재사용하는 대신,
  코어에 `create_text_document`를 만들고 `create_document`를 파싱 어댑터로 축소했다.
  **`git diff --stat main -- backend/app/services/`의 실제 수치를 본문에 적어라.**
  그리고 이 변경이 **"인터페이스 추가 때문"이 아니라 "코어 어휘 정정 때문"**임을 구분해
  기록하라 — PRD §4 판별 기준 3("인터페이스를 추가할 때 코어가 몇 줄 바뀌는가 = 0")의 실측은
  이 진입점 위에 MCP 쓰기 도구(M11-d)가 얹힐 때 나온다. **0줄이 아니라고 해서 판별 기준이
  깨진 것처럼 쓰지 말고, 반대로 0줄인 것처럼 꾸미지도 마라.**
  라우터 encode 방식을 택하지 않은 이유도 적어라: 그 방식의 0줄은 경계가 잘 그어져서가 아니라
  인터페이스가 코어의 파일 중심 어휘에 자기를 구겨 넣어서 나온 숫자이며,
  `scripts/seed_demo.py`의 우회를 공식 API 표면으로 승격시킨다.
- **결정 2 (귀속과 출처).** 직접 공급 문서의 `filename`은 NULL이다. 요청은 `filename`도
  `owner_id`도 받지 않는다 — 주체는 세션에서만 해석되고(PRD §6 R4 사칭 불가), 출처
  (provenance) 필드는 이번에 도입하지 않는다(R6 — 외부 소스 연결 시점의 별도 스키마).
- **결정 3 (어휘 — ADR-017 정합).** `documents.content`의 정본 명칭은 **"문서 텍스트"**이고,
  그중 파일 업로드 경로에서 만들어진 것이 **"추출 텍스트"**다(`filename IS NOT NULL`).
  ADR-017의 세 용어 구분은 폐기가 아니라 상위 개념 하나를 얻는다. "직접 공급된 텍스트도
  추출 텍스트로 부른다(추출이 항등 변환)"는 대안을 택하지 않은 이유를 적어라 — 어휘를
  지키려다 어휘를 비우는 쪽이다. Web UI 반영은 step 4가 했다.
- **결정 4 (형식).** 텍스트로 공급 가능한 유형은 `txt`·`md`다. **pdf/docx의 base64 공급을
  도입하지 않는다** — 바이너리는 기존 multipart 업로드가 담당한다.
- **결정 5 (CORS — 도입하지 않음).** `ROADMAP.md` 1단계 착수 조건 중 하나였다. 비브라우저
  소비(curl·서버 간·MCP)는 CORS와 무관하고, 지금 열면 인증이 세션 쿠키뿐이라 CSRF 표면만
  생긴다. **브라우저 서드파티 소비는 이번에 열지 않으며, 재검토는 비대화형 자격증명(M11-c)
  이후다.** "필요 없어서 안 했다"가 아니라 "지금 열면 무엇이 위험한지"를 적어라.
- **결정 6 (요청 본문 크기 가드 — 라우터에 두지 않음).** 실측 근거를 남겨라:
  `fastapi/routing.py`의 요청 핸들러는 `body_bytes = await request.body()`로 본문을 먼저 읽은
  뒤 `solve_dependencies(...)`를 호출한다. 따라서 라우터·의존성 수준의 `Content-Length` 검사는
  본문이 이미 메모리에 올라온 뒤에 도는 장식이다. 실효 경계는 서비스의
  `MAX_EXTRACTED_TEXT_LENGTH`(500,000자)가 400으로 지키며 테스트가 미저장까지 단언한다.
  전송 층 상한은 리버스 프록시·미들웨어의 몫이며 이번에 도입하지 않는다.
- **트레이드오프.** 최소한 다음 둘을 정직하게 적어라.
  ① `examples/ingest_text.py`가 **실제로 도는지는 CI가 확인하지 않는다** — pytest가 지키는
  것은 의존성 독립·문법 유효성·경로 대조 셋뿐이고, 실행 확인에는 실서버 기동이 필요하다.
  ② 인증은 여전히 세션 쿠키뿐이라 **프로그램 주체는 아직 없다** — 예제 클라이언트도 사람의
  username/password로 로그인해 쿠키를 얻는다. PRD §6의 "프로그램(REST) — 비대화형 자격증명"은
  여전히 미구현이며 M11-c(ADR-034)의 몫이다.

### 3) `docs/PRD.md`

- §5 능력 표의 C4 상태 열 — 지금 상태를 정확히 적는다. **"프로그래매틱 공급 미착수"는 더 이상
  참이 아니고, "완료"도 참이 아니다.** 텍스트 공급 경로는 구현됐고 비대화형 자격증명은 없다
- §5 C4 본문의 **공급** 문단 — "현재 구현된 경로는 Web UI의 파일 업로드 하나다"와 "정의가
  구현을 앞서는 유일한 항목"을 지금 상태로 고친다. 남은 부분(비대화형 자격증명)이 무엇인지
  명시하라
- §4 경계 절의 "**공급자 쪽 N은 아직 주장이다**" 문장 — 실측으로 갱신한다. 다만 **판별 기준 3의
  0줄 실측은 아직 나오지 않았다**(결정 1 참조). 있지도 않은 증거를 적지 마라
- §6 「주체별 필요 수준」 표의 "프로그램 (REST)" 행은 **❌ 부재를 유지한다** — 이 phase는
  자격증명을 만들지 않았다

- 「단계적 발전 경로」 1단계 행의 "착수 전 필요한 결정" — 해소된 둘(텍스트 API 의미론 ·
  CORS 정책)이 ADR-035로 확정됐음을 표시하고, 남은 것(토큰 인증 · 첫 커넥터 · MCP 쓰기 도구)을
  남긴다
- 「다섯 구분으로 본 현재 구조」 표의 **Ingestion** 행 — "진입점 1개"가 더 이상 참이 아니다

### 5) `docs/UI_GUIDE.md`

- 「용어 규칙」 표에 **문서 텍스트**를 상위 개념으로 추가하고, 원본 파일이 없는 문서
  (`filename` 없음)의 편집 영역 레이블이 "문서 텍스트"임을 규칙으로 적는다
- 기존 「추출 텍스트 편집」 절의 pdf/docx 상시 안내 규칙은 **그대로 유지한다**

### 6) `CLAUDE.md`(저장소 루트)

「아키텍처 규칙」의 추출 텍스트 항목을 갱신한다. 요지: 문서 텍스트가 상위 개념이고, 원본 파일이
없는 문서(`filename IS NULL`)가 존재하며, 그 문서에 "추출"이라는 말을 쓰지 않는다.

**기존 규칙 줄을 통째로 교체하지 말고 필요한 만큼만 고쳐라.** 이 파일의 다른 CRITICAL 규칙을
건드리지 마라 — 특히 **금지어·경고 문구의 원문을 지우지 마라.** 규칙 문서에서 원문이 사라지면
규칙 자체가 사라진다.

2. 문서 정합 체크리스트를 **직접 읽어** 확인한다 (grep으로 대체하지 마라):

   - 기존 ADR 본문을 소급 수정하지 않았는가? (ADR-032 트레이드오프의 원칙 — 가리키는 대상이
     이동한 곳에는 주석만 단다)
3. 결과에 따라 `phases/m11b-text-ingest/index.json`의 step 5를 업데이트한다:

## 금지사항

- **코드를 고치지 마라.** 이유: 이 step은 문서 전용이다. 문서를 쓰다가 코드 문제를 발견하면
  고치지 말고 `blocked`로 멈추고 사유를 적어라 — 문서 커밋에 코드 수정이 섞이면 리뷰에서
  둘 다 검증되지 않는다.
- **ADR-033·034를 만들지 마라.** 이유: 각각 ZIP 대량 투입(#54)과 프로그래매틱 인증 토큰
  (M11-c)에 예약된 번호다. 지금 채우면 그 이슈들이 번호를 잃는다.
- **기존 ADR 본문을 소급 수정하지 마라.** 이유: ADR은 결정 당시의 기록이다. 가리키는 대상이
  이동한 곳에는 이동처를 알리는 주석만 단다 (ADR-032 트레이드오프가 세운 원칙).
- **PRD §6 「주체별 필요 수준」의 "프로그램 (REST)" 행을 ✅로 바꾸지 마라.** 이유: 이 phase는
  비대화형 자격증명을 만들지 않았다. 예제 클라이언트도 사람의 비밀번호로 로그인한다.
- **`CLAUDE.md`·`UI_GUIDE.md`의 금지어·경고 문구 원문을 지우지 마라.** 이유: 규칙 문서에서
  원문이 사라지면 규칙이 사라진다. 이 저장소에서 실제로 발생한 사고다.
- **마이그레이션 SQL 파일의 주석을 고치지 마라.** 이유: 적용된 마이그레이션 파일은 수정
  대상이 아니다 (ADR-005). `002_tables.sql`의 `content` 컬럼 주석이 "추출 텍스트"인 것은
  그대로 둔다.
- **README를 이 step에서 고치지 마라.** 이유: 이 phase의 문서 반영 대상은 위 여섯 파일이다.
  README 갱신이 필요하다고 판단되면 summary에 적고 PR 리뷰에서 다룬다.
